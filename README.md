# Tercera-Actividad-TV

En esta actividad, se presenta un diagrama UML de un objeto llamado "TV", el cual cuenta con 3 atributos privados:
- channel: int
- volumenLevel: int
- on: boolean

Además de métodos públicos como:
- TV()
- turnOn()
- turnOff()
- setChannel(int newChannel): void
- channelUp(): void
- channelDown(): void
- volumeUp(): void
- voulmeDown(): void

A continuación, el ejercicio principal de la actividad: escribir el código en Java
